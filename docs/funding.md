# Funding & sustainability

Slop AI is and will remain MIT-licensed. There is no commercial product;
there is no paid tier; there are no upsells. The project's sustainability
plan is community funding.

## Where to donate

- **GitHub Sponsors** — [github.com/sponsors/slop-ai](https://github.com/sponsors/slop-ai)
- **OpenCollective** — [opencollective.com/slop-ai](https://opencollective.com/slop-ai)
- **Tidelift** — Slop AI is a participating package in the Tidelift
  Subscription. If your organization already has Tidelift, this gets you
  a security & stability commitment without changing licenses.

## Where the money goes

We publish quarterly transparency reports listing every disbursement.
Funds are spent in this priority order:

1. Hosting (sync server reference instance, docs site, CDN for icon and
   schema assets).
2. Security audit costs (annual cryptography + plugin sandbox audit).
3. Maintainer stipends, capped per quarter so funding never creates
   pressure to ship to a deadline.
4. Bounties for major features (see [`docs/bounties.md`](bounties.md)).
5. Community grants for plugin authors building on the V3.0 SDK.

## Bounties

We post bounties on important features that the maintainer team can't
prioritize. Bounty PRs go through the same review process as everything
else; the bounty pays out on merge.

## What we will not do

- We will not relicense to a "source-available" or "BSL" license.
- We will not gate any feature behind a paywall in the upstream.
- We will not bundle ad SDKs, telemetry-by-default, or telemetry that
  reports user content.
- We will not centralize sync; self-hosted is the only first-party
  deployment shape.
