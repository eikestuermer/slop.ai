# integration-a11y

Closes `S-VERIF-004`. Runs Playwright + axe-core against a built `apps/web` server, asserts zero WCAG 2.2 AA violations.

## Job body

The current `ci.yml` body has a real implementation; the issue Phase A surfaced is the `pnpm add -D` line needs the `-w` flag in our workspace:

```yaml
- name: Install Playwright + axe
  run: |
    pnpm add -wD @axe-core/playwright playwright
    npx playwright install --with-deps chromium
- name: Start web companion + run audit
  run: |
    pnpm --filter @slop/web build
    pnpm --filter @slop/web preview &
    sleep 5
    SLOP_AXE_URL=http://localhost:5174 node scripts/a11y-audit.mjs
```

The audit script itself is already implemented at [scripts/a11y-audit.mjs](../../../../scripts/a11y-audit.mjs); it loads the URL, runs `AxeBuilder` with `wcag22aa` tags, and exits non-zero if any violation is reported.
